⚽ FPL Dashboard — Setup Guide

Zero assumptions. Follow top to bottom.

Part 1 of 3
Get the files ready on GitHub
1

Create a GitHub account

Go to github.com and sign up. It's free. This is just a place to store your code online so Streamlit can find it.

2

Create a new repository

Click the + icon top-right → New repository.

Name it fpl-dashboard. Leave it set to Public. Click Create repository.

It must be Public — Streamlit's free hosting tier requires this.
3

Upload the main files

On your new repo's page, click uploading an existing file.

Drag in these files (from what Claude gave you): app.py, fpl_data.py, strategy.py, claude_reasoner.py, visuals.py, requirements.txt, README.md.

Scroll down, click Commit changes.

4

Add the two "pages" files (in their own folder)

Click Add file → Create new file.

In the filename box, type exactly: pages/1_Transfers_and_Chips.py — typing the slash makes GitHub create the folder automatically.

Paste in that file's contents below the filename box, then Commit changes.

Repeat the same process for pages/2_Agent_Briefing.py.

5

Add the theme file

Same trick: Add file → Create new file → filename .streamlit/config.toml → paste its contents → commit.

This makes the app look green/orange instead of default gray.

Checkpoint: your repo should now show two folders (.streamlit, pages) plus the loose files from Step 3. If something's missing, re-check the filename spelling — it has to be exact.
Part 2 of 3
Deploy it so you can open it on your phone
6

Sign up for Streamlit Community Cloud

Go to share.streamlit.io → Sign in with GitHub → authorize it when asked.

7

Deploy the app

Click New app. Pick your fpl-dashboard repository. Set the main file path to app.py. Click Deploy.

Wait 1–2 minutes. You'll land on a live URL like yourname-fpl-dashboard.streamlit.app.

8

Add your Anthropic API key as a secret needed for Agent Briefing page

First, get a key: go to console.anthropic.com, sign up, add a small amount of billing credit, then create an API key.

Back in Streamlit Cloud: open your app → Settings → Secrets. Paste in:

ANTHROPIC_API_KEY = "sk-ant-your-real-key-here"

Save. This keeps the key private — it never goes into your public GitHub repo.

9

Put it on your phone's home screen

Open the .streamlit.app link on your phone in Chrome. Tap the ⋮ menu → Add to Home screen.

You now have an app icon that opens full-screen, like a real app.

Part 3 of 3
Optional: the automated email agent runs on your computer, not your phone
10

Open the project in PyCharm

Put all the fpl_agent files Claude gave you (agent.py, fpl_client.py, strategy.py, claude_reasoner.py, visuals.py, emailer.py, backtest.py, requirements.txt, .env.example) into one folder. Open that folder as a project in PyCharm.

11

Get a Gmail "app password"

This is different from your normal Gmail password — Google requires it for scripts sending email.

Turn on 2-factor authentication on your Google account if it isn't already, then go to myaccount.google.com/apppasswords and generate one. Copy the 16-character code.

12

Create your .env file

In PyCharm's file list, copy .env.example and rename the copy to exactly .env.

Open it and fill in your real values: your Anthropic API key, your FPL team ID, the rival team ID you want to benchmark against, your Gmail address, and the app password from Step 11.

13

Install dependencies and run it

Open PyCharm's terminal (bottom toolbar) and run:

pip install -r requirements.txt
python agent.py

Leave this terminal window open — the agent checks every 30 minutes and only emails you once, within the window before each deadline (default 3 hours, adjustable in .env).

Closing the terminal stops the agent. See README_agent.md for how to keep it running long-term (tmux on Mac, Task Scheduler on Windows).
14

Try the backtest first

Before waiting for a real deadline, test everything works by running:

python backtest.py --event 1 --send

Check your inbox for an email clearly marked [BACKTEST].

Final checklist
  • GitHub repo created with all files in the right folders
  • App deployed and loads at your .streamlit.app URL
  • Anthropic API key added under Streamlit Secrets
  • App icon added to phone home screen
  • (Optional) .env filled in for the local agent
  • (Optional) Backtest email received successfully
